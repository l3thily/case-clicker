# Case Clicker

Браузерный ремейк мобильной игры Case Clicker на настоящих кейсах CS2.

**Играть:** https://l3thily.github.io/case-clicker/

## Что внутри

- **Кликер** — деньги за клики, улучшения (сила клика, автокликер, хедшот ×10, оффлайн-доход), ежедневная награда, звания от Silver I до Global Elite (каждое даёт +5% к доходу).
- **42 оружейных кейса CS2** — от CS:GO Weapon Case до Fever Case, с реальным составом и картинками из Steam.
- **Честные шансы как в игре:** армейское 79.92%, запрещённое 15.98%, засекреченное 3.2%, тайное 0.64%, нож/перчатки 0.26%; StatTrak™ 10%; float равномерно в диапазоне скина, износ FN/MW/FT/WW/BS.
- **Цены Steam Market** для каждого скина, износа и StatTrak™; кейс + ключ $2.49. На странице кейса — средняя стоимость дропа и окупаемость.
- **Инвентарь** с продажей по рыночной цене, массовой продажей и карточкой предмета (float, паттерн).
- **Контракты обмена** по правилам CS2: 10 предметов → следующее качество, 5 тайных → нож/перчатки; float результата считается из нормализованных float.
- **Апгрейд** предметов с колесом шанса, **маркет**, мини-игры **краш** и **монетка**, статистика и 19 достижений.
- Сохранение в браузере + перенос через код сохранения.

## Данные

`data/cases.js` собирается скриптом `tools/build_data.py`:

- состав кейсов, float-диапазоны и изображения: [ByMykel/CSGO-API](https://github.com/ByMykel/CSGO-API);
- цены Steam Market (среднее за 7 дней, фолбэк — Skinport): [prices.csgotrader.app](https://csgotrader.app).

GitHub Action `prices.yml` пересобирает данные каждый понедельник, так что цены остаются актуальными.

```bash
python3 tools/build_data.py   # обновить данные вручную
python3 -m http.server        # запустить локально → http://localhost:8000
```

Фанатский проект без коммерческой цели. Не связан с Valve. Игровые деньги ненастоящие.
